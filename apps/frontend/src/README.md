# Frontend Source

## Purpose
Main client application codebase for the Face Match user interface.

## Internal Architecture
- `app`: Top-level page components, layout styling, and route pages.
- `components`: Reusable UI building blocks and view components.
- `hooks`: Custom React state and lifecycle hooks.
- `lib`: Shared API clients, utility helpers, and TypeScript definitions.
- `main.tsx`: React DOM application entry point with client-side routing.
