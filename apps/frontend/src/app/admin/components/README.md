# Admin Components

## Purpose
Route-owned UI components for the Album Ingestion administration workspace.

## Components
- `admin-stats-bar.tsx`: Clean hairline-divided horizontal stat bar tracking albums, stored photos, and precomputed face vectors.
- `folder-indexing-form.tsx`: Google OAuth connection card and Drive folder indexing submission form.
- `indexed-folders-table.tsx`: Responsive album registry switching cleanly between hairline mobile cards and a desktop data table.
