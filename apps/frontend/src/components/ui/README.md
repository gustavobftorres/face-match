# UI Primitives

## Purpose
Minimal, high-craft UI primitives blending Antigravity pill shapes and hairline borders with the SIQUI warm cream canvas, espresso ink, and cheerful accent palette.

## Components
- `button.tsx`: Motion-enabled rounded-full pill buttons (`primary`, `orange`, `lilac`, `outline`, `ghost`, `danger`).
- `badge.tsx`: Pastel semantic status pills (`neutral`, `success`, `warning`, `danger`, `lilac`, `orange`, `ink`).
- `card.tsx`: Clean rounded-3xl white card with hairline espresso border.
- `input.tsx`: Pill-shaped `min-h-[44px]` input with marigold focus halo.
- `panel.tsx`: Framed bento workspace surface with subtle color dot indicator and hairline header separator.
