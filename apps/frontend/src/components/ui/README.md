# UI Components

This directory contains base UI components designed with the Antigravity aesthetic (glassmorphism, fluid animations).

## Components
- \`input.tsx\`: Styled input fields.
- \`button.tsx\`: Primary and secondary buttons with hover effects.
- \`card.tsx\`: Glassmorphic card containers.

## Usage
\`\`\`tsx
import { Button } from "@/components/ui/button";

<Button>Click Me</Button>
\`\`\`
