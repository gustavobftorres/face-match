# Shared Components

## Purpose
Reusable UI primitives, responsive layout framing, and theme visual details shared across application routes.

## Subdirectories
- `ui/`: Rounded pill buttons, pastel badges, bento panels, cards, and inputs.
- `layout/`: Sticky navigation header, floating mobile dock, and wave horizon footer.
- `theme/`: Poster-inspired vector details and interactive `<AntigravityParticles />` canvas.
