# Theme Visuals

## Purpose
Custom visual motifs and interactive canvas particles implementing the poster-inspired light color palette and Antigravity spatial motion.

## Components
- `theme-motifs.tsx`: Minimal vector details (`DaisyMark`, `SquiggleUnderline`, `WaveHorizon`).
- `antigravity-particles.tsx`: Responsive `<canvas>` capsule particle ring with central headline clear-zone and reduced-motion support.
